GIF-Optimizer-CLI shrinks animated GIF files by reducing the color palette, deduplicating identical consecutive frames, and resizing, all using only the Go standard library. It builds a shared histogram across every frame, keeps the most-used colors, and redraws each frame with Floyd-Steinberg dithering, while a nearest-neighbor scaler preserves frame offsets during resize. When duplicate frames are collapsed, their delays are folded into the surviving frame so playback timing stays intact, and the CLI prints a before-and-after size delta on every run.
